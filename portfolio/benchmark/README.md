# Unified Benchmark

Benchmark 用统一的分配、释放和生命周期场景，比较不同工具在以下维度的表现：

- 是否识别出预设泄漏；
- `blocks` 和 `bytes` 是否接近 ground truth；
- 是否能保留调用路径并完成聚合；
- 运行时间、输出规模和使用约束。

基础场景覆盖无泄漏、明确泄漏、持续增长、延迟释放、高频无泄漏和混合负载。扩展场景加入了场景加载、帧临时对象、异步资源、网络包、音频缓冲和缓存淘汰等游戏语义代理路径。

`source/` 中保留可独立阅读的 benchmark、runner 和 summarizer。实验结果只保留用于展示的汇总表，不包含服务器原始日志。
